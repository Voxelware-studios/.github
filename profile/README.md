## About Us

**Voxelware Studios** is a software development studio focused on building modern software, developer tools, and infrastructure for Minecraft communities.

We believe great software should be reliable, extensible, performance-oriented, and accessible to developers. Our goal is to create practical solutions that simplify server management, improve community experiences, and provide developers with the tools they need to build better software.

From server-side platforms and plugins to APIs and community integrations, we focus on engineering solutions that make a difference.

## What We Build

| Area | Focus |
|---|---|
| Minecraft Software | Plugins, server platforms, and ecosystem tools |
| Developer Tools | APIs, libraries, frameworks, and utilities |
| Community Solutions | Discord bots, integrations, and automation |
| Infrastructure | Server management, performance, and deployment solutions |

## Our Projects

### CoreTuff
An open-source Minecraft server management and utility project designed to provide server administrators with useful functionality and extensible capabilities.

### SmokeUtils
A Discord bot project focused on community management, moderation, and automation.

### VeltisMC
An independent Minecraft server software project focused on performance, extensibility, and modern server architecture.

> Explore our GitHub repositories to discover our projects, development progress, and contributions.

## Our Philosophy

We build software around a few fundamental principles:

- **Open Source:** Encourage transparency, collaboration, and community-driven development.
- **Performance:** Build efficient software without unnecessary overhead.
- **Extensibility:** Design systems that developers can customize and extend.
- **Reliability:** Prioritize stability, maintainability, and predictable behaviour.
- **Innovation:** Explore better approaches to existing engineering challenges.

## Open Source & Contributions

We believe open-source development is stronger when developers collaborate.

Whether you're reporting a bug, suggesting an improvement, contributing code, or helping with documentation, your contributions are valuable.

You can get involved by:

- Reporting bugs through GitHub Issues.
- Suggesting features and improvements.
- Submitting pull requests.
- Improving documentation.
- Participating in community discussions.

Please check individual repository guidelines before contributing.
